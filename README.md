# SiteWalk

Job site documentation made simple.

Walk the site, take photos, record voice notes, and get instant AI-generated reports.

## Getting Started
Open index.html in your browser to try the prototype.

Voice notes record audio and transcribe live with the Web Speech API (best in Chrome on Android). Transcripts are tagged with the selected trade and included in the printed report. Audio is kept as a backup when captions miss words.

Works best over HTTPS. Microphone permission is required.

Built with the user for real construction workflows.
